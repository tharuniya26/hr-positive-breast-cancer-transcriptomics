# Dataset selection

## Research comparison

The primary contrast is source-labelled **Luminal B minus Luminal A** in primary invasive breast tumours. This addresses transcriptomic heterogeneity within labelled luminal groups. It does not establish ER or PR immunohistochemistry status for individual tumours and does not independently reproduce PAM50 classification.

## Candidates

| Dataset | Strength | Reason for decision |
|---|---|---|
| GEO GSE45827 | Processed GPL570 matrix; 29 Luminal A and 30 Luminal B tumours; batch and subtype fields | Selected; moderate download and balanced batch representation |
| GEO GSE2034 | 286 breast tumours, GPL96, outcome data | Less direct luminal A/B labels in the GEO matrix; extra classification needed |
| TCGA-BRCA | Broad molecular and clinical data | More complex data access, expression type and annotation reconciliation for a first reproducible project |

GSE45827 was generated by Gruosso et al. for a study focused on oxidative stress and H2AX, rather than this luminal comparison ([GEO accession](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE45827); [original article](https://doi.org/10.15252/emmm.201505891)). The source matrix contains 155 columns: 130 tumours, 11 normal tissues and 14 cell lines. This analysis includes only the 59 labelled luminal tumours. There is no evidence in the matrix that receptor status was reassayed for this project.

The Affymetrix Human Genome U133 Plus 2.0 platform (GPL570) measurements were reported as GC-RMA normalized log2 signals. GEO describes a subsequent mixed-model analysis with batch and hybridization adjustment and averaging of technical replicates, but the matrix metadata do not prove every stored value is free of batch effects. We therefore include batch as a covariate in differential expression and inspect PCA by batch. Technical replicates are represented by one GSM column and are not treated as independent samples.
