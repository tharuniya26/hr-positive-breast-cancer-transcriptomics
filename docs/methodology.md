# Methods

**Study design.** Secondary, observational reanalysis of GSE45827 GPL570 microarrays. Include 29 labelled Luminal A and 30 labelled Luminal B primary invasive tumour columns. Exclude other tumour types, normal tissues and cell lines. No patient outcomes or treatment labels are available for this comparison.

**Expression and annotation.** The series matrix has 29,873 GC-RMA log2 probe-set rows and 155 GSM columns. The 2016 GPL570 annotation maps measured probes to gene symbols. Ambiguous symbols with multi-gene delimiters and unmapped probes are removed. One probe per gene is selected by largest across-sample mean intensity, before inspecting subtype differences. This reduces 29,873 probes to 13,823 genes; some gene isoforms and probes are thereby omitted. No RNA-seq normalization or extra log transformation is applied. Inputs with missing values, duplicate IDs or unexpected sample counts fail validation.

**QC.** Per-sample median, IQR and missing fraction are calculated. PCA uses the 3,000 genes with highest across-sample variance after centring. PCA is exploratory and does not determine exclusions. Batch labels 1–5 occur in both luminal groups. No outlier was excluded post hoc.

**Differential expression.** For each gene, a fixed-effects linear model fits intercept, Luminal B indicator and four batch indicators. The B coefficient is a log2 signal difference relative to A and is interpreted as a log2 fold change on the preprocessed intensity scale. Gene residual variances are moderated toward a common scaled inverse-chi-square prior estimated from log variances; moderated two-sided t p-values are adjusted by Benjamini–Hochberg across all 13,823 genes. The code is an independent, limited implementation of the limma empirical-Bayes approach, **not** Bioconductor limma. It assumes complete measurements, shared residual degrees of freedom, no sample-level dependence after GEO replicate handling, and common prior variance distribution. No clinical or treatment covariates were available. Significance is FDR <0.05; a secondary descriptive hit list also requires |log2 difference| ≥0.5. Statistical significance alone does not show functional importance.

**Enrichment.** Hypergeometric over-representation uses the 13,823 tested genes as universe and the secondary hit list as foreground. Reactome release 97 GMT gene symbols are intersected with that universe; tested sets contain 10–500 measured genes. BH adjustment is across all tested sets. Pathways overlap extensively. ORA is non-directional and does not establish pathway activation or repression. The exact release 97 file is SHA-pinned (see [provenance](data_provenance.md)).

**Visualizations.** Figures 2–6 derive from measured data. Figures 1, 7 and 8 are workflow or literature-based conceptual diagrams. Marker plots show individual normalized log2 signals, group means and approximate 95% normal confidence intervals. The heatmap uses row-wise z scores for display and must not be interpreted as absolute expression differences.

**Reproducibility.** `python -m scripts.run_analysis` generates all output tables and figures. The same input SHA-256 values, Python environment and code should reproduce tabular values up to floating-point variation. See `results/summary.json` for checksums and counts.
